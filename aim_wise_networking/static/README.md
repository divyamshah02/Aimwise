# Aim Wise Networking - Landing Page Website

A modern one-page static website for **Aim Wise Networking**, a digital marketing agency.

## ✨ Features

- **Light & Dark Theme Toggle** – user can switch between light and dark modes.
- **Custom Cursor Animation** – smooth trailing cursor effect with ripple interactions.
- **Frosted Glass Navbar** – fixed navbar with blur effect for premium look.
- **Shrinking Navbar on Scroll** – navbar reduces padding and adds subtle shadow when scrolling.
- **Smooth Animations** – footer and sections fade in dynamically.
- **Responsive Design** – mobile-friendly layout using HTML, CSS, and JS.
- **Services Section** – SEO, SMM, Paid Ads, Web/Creative Design with benefit-driven copy.
- **Work Section** – showcases projects with improved CTA button.
- **Contact Section** – improved form with clear CTA ("Send Inquiry").
- **Footer** – modern social icons + credits: Developed & Managed by [Dynamic Labz](https://www.dynamiclabz.net/).

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **Vanilla JavaScript (ES6)**

## 📂 Project Structure

```
index.html       # Main HTML file
style.css        # Styles (light/dark mode, animations, layout, navbar)
script.js        # Interactivity (theme toggle, cursor, scroll animations)
assets/          # Images, logos, icons (if any)
README.md        # Documentation
```

## 🚀 How It Works

1. Open `index.html` in a browser to view the site.
2. Navbar is fixed and shrinks on scroll with frosted glass effect.
3. Toggle between **light/dark themes** via the switch button.
4. Scroll animations trigger on sections and footer.
5. Contact form is styled but needs backend integration (e.g., Formspree).

## 📌 Notes
